# xiaominART website

Astro + Sanity + Vercel website for `xiaominart.com`, focused on quiet living, gift guidance and thoughtful commissions. The current production MVP uses a warm paper canvas, editorial serif typography, restrained motion and Chinese-first content.

## Included

- Gift-led homepage with scene and budget entry points.
- `/gift-guide/`: scene and budget filters, five structured gift directions, local wishlist and gift FAQ.
- `/gift-guide/[slug]/`: gift meaning, recipient guidance, packaging, dispatch reference and consultation CTA.
- `/scenes/`: study, living room, tea room, gifting and business-gift contexts.
- `/business-gifts/`: corporate gift tiers, use cases, inquiry form prototype and FAQ.
- `/journal/`, inspiration pages, artist page, commission pages and bilingual entry points.
- Mobile fixed quick actions for gifts, filters, wishlist and consultation.
- No checkout, payment, inventory, order or real form backend is claimed; transaction functionality remains a later phase.

## Local development

```bash
npm install
npm run dev
npm run check
npm run build
```

## Deployment

The site is deployed as a static Astro build on Vercel. Production aliases are `https://xiaominart.com` and `https://www.xiaominart.com`.
