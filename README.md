# xiaominART

独立的小民艺术网站仓库，与 Geektion 完全无关。

## 目录

- `hugo-site` 的内容已放在仓库根目录：Hugo 静态官网 + GitHub Pages + Cloudflare 准备配置。
- `xiaominart-test-site/`：Node + SQLite 销售型测试工程，包含源码、测试、数据库结构、演示数据、后台和复验材料。

## 当前状态

这是部署准备/待验收仓库，不是正式上线版本。未接入真实支付，未修改正式 DNS，未导入真实客户数据。

静态官网部署说明见 `DEPLOY-HUGO-GITHUB-CLOUDFLARE.md`；测试工程说明见 `xiaominart-test-site/README.md`。
