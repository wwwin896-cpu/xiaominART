**为什么私信不做成「点一下跳飞书」**：飞书机器人 webhook 是「往群里发消息」的接口，只接受程序 POST。访客点开在浏览器里看到的会是 `{"code":...}` 或错误页。所以做成弹层留言 → 服务端转发，效果是「留言直接进飞书群」，访客端干净。

## 二、需要您在 Cloudflare 配的 5 个环境变量

位置：Cloudflare Dashboard → Workers & Pages → 选中本项目 → Settings → Variables and Secrets → 逐个 Add（类型选 **Secret**）→ 保存后 **Redeploy** 一次才生效。

| 变量名 | 填什么 | 说明 |
|---|---|---|
| `FEISHU_WEBHOOK_URL` | 您发我的那条 `https://open.feishu.cn/open-apis/bot/v2/hook/...` | 飞书群机器人地址 |
| `FEISHU_KEYWORD` | 机器人「安全设置」里的**自定义关键词** | 不填 = 飞书会拒收（见第三节） |
| `RESEND_API_KEY` | `re_V9CSPYUB_...` | Resend 发信密钥 |
| `RESEND_TO_EMAIL` | 您收线索的邮箱 | 有新线索时抄送您 |
| `RESEND_FROM_EMAIL` | `notice@xiaominart.com` | **必须等域名验证通过后再填**，否则发信 403 |

> 前两项没配 = 私信照常进数据库，但不推飞书；中间三项没配 = 订阅照常落库，但不发欢迎邮件。都有降级，不会报错给访客。

## 三、飞书机器人：现在被「关键词」拦住了

我实测发了两次，都返回：

```
{"code":19024,"msg":"Key Words Not Found"}
```

意思是机器人开了「自定义关键词」安全校验，消息里必须出现那个词。两种解法，您选一个：

**A. 告诉我是哪个关键词**（推荐，最快）
您回复一个词即可，我填进 `FEISHU_KEYWORD`，全站通知都会带上它。

**B. 改成「签名校验」**
飞书群 → 机器人设置 → 安全设置 → 选「签名校验」→ 把 secret 发我。
我在服务端加 HMAC 签名（约 10 分钟），之后消息内容不受限制。

## 四、Resend：域名还没验证（这是欢迎邮件不发的唯一原因）

实测发信返回：

```
The xiaominart.com domain is not verified.
```

现在的 API key 只有「发送」权限，我无法代您加域名。需要您做（约 10 分钟）：

1. 打开 resend.com/domains → **Add Domain** → 填 `xiaominart.com`
2. 页面会给出 3–4 条 DNS 记录（MX / TXT / CNAME 形式，含 DKIM）
3. 到 Cloudflare → 选 `xiaominart.com` → DNS → **逐条添加**（代理状态选「仅 DNS / DNS only」）
4. 回 Resend 点 **Verify**，状态变成 Verified 即可
5. 把 `RESEND_FROM_EMAIL=notice@xiaominart.com` 加进环境变量并 Redeploy

验证通过后，任何人订阅都会立刻收到那封「欢迎 + 字游记第一站」的邮件。

**如果您愿意改用全权限 API key**（Resend → API Keys → Create，权限选 Full access），把新 key 发我，域名添加和 DNS 记录我可以在 3 分钟内查出来给您照着填，省掉第 1 步的摸索。
