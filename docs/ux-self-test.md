# XiaominART C 端访客体验自测

**测试对象**：`http://127.0.0.1:4321/` 现有 Astro Demo  
**视角**：普通 C 端访客  
**范围**：首页、导航、灵感参考库、定制入口、电商残留、整体品牌观感  
**结果**：通过；已修复发现的明确负面体验点

## 1. 首页第一印象

**修复前**：Hero 已表达共创，但“不售卖现成画作”的字面边界位于首屏下方，第一眼仍存在轻微购买误解空间。  
**修复后**：Hero 主标题下新增：

> 不售卖现成画作，仅接受艺术定制共创。  
> No ready-made artwork for sale; commissions only.

结论：访客进入首页后，可直接理解这是艺术定制共创服务，不是现货画作商店。

## 2. 导航、Logo 与标题

- 导航使用 `1.15rem`，保留原字距、行高与字重，桌面链接保持 `nowrap`。
- Logo 内容保持 `XiaominART`，字体改用 `--font-logo` 圆润柔和回退栈。
- Hero、区块标题和作品标题使用统一标题字距与中等字重。
- 纸白、墨色、朱砂与大地色细线保持不变。
- 结论：导航信息可扫描，Logo 观感柔和，标题层级克制，不出现廉价电商式促销视觉。

## 3. 灵感参考库

每张灵感卡片继续显示完整提示：

> 案例仅作风格参考，不售卖同款 | For reference only, identical artwork is not for sale.

卡片主链接进入参考详情；主要行动统一为：

> 以此为灵感定制 / Commission from this direction →

结论：不会把灵感案例误解为可直接购买的现成作品。

本轮将卡片提示字号由 `11px` 调整为 `12px`，并增加 `line-height: 1.65`，提升移动端可读性。

## 4. 定制咨询入口

- Sticky Header 常驻：`开启定制咨询 →`
- Hero 主按钮：`开启定制咨询 / Begin a consultation →`
- 首页流程、艺术家、灵感库、艺术礼盒和 B 端区域均有定制入口。
- 目标统一为 `/custom-commission/`。

结论：普通访客可在首屏和导航快速找到定制咨询入口。

## 5. 电商残留检查

源码与页面路径扫描未发现：

- 购物车
- Checkout
- 立即购买
- 加入购物车
- Buy now
- Add to cart
- 价格标签
- 库存数量
- 折扣、秒杀、优惠券、包邮等促销元素

页面中涉及“价格/库存”的文字只出现在事实边界说明中，不构成购买入口或营销元素。

## 6. 其他明确体验点修复

- 页脚移除“联系邮箱（待确认）”占位，改为通过定制表单联系：`联系 XiaominART / Contact via commission form`。
- 表单提示由“正式线上表单服务待接入”改为：

  > 提交后将打开默认邮件客户端，请在发送前检查内容。

  这样保留 Demo 的真实行为说明，同时不以内部工程状态打断访客体验。

## 7. 移动菜单

源码保留移动端菜单按钮、`aria-expanded`、`nav.open`、点击链接关闭和 `Escape` 关闭逻辑。自动化浏览器测试中菜单展开状态未能稳定复核，未将其判定为已确认缺陷；建议下一轮在真实浏览器中人工点击确认。

## 8. 总体判断

**结论：更接近高级艺术品牌，而不是普通廉价电商。**

依据：低饱和大地色、衬线标题、编辑式留白、无价格与促销、无购买流程、案例均导向定制咨询、内容围绕意图与共创组织。
