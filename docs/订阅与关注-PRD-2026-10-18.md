## 第一期：已上线（2026-10-18）

### 1. 订阅（Email）

| 项 | 现状 |
|---|---|
| 入口 | 全站页脚「订阅和关注」区块（Newsletter 组件） |
| 存储 | WorkBuddy 云数据库 `subscribers` 表（email + source + 时间），经 `/api/lead` 代理落库 |
| 防重复 | 云端 409 = 已订阅，前端提示「无需重复提交」 |
| 欢迎邮件 | 落库成功即发（Resend），内容含字游记第一站链接；**发件域名未验证时静默跳过**（详见 1.1） |
| 退订（过渡） | 订阅者回复邮件；第二期换一键退订 |

**1.1 欢迎邮件生效的唯一前提**：在 resend.com/domains 验证 `xiaominart.com`，并在 Cloudflare Pages 环境变量加 `RESEND_FROM_EMAIL=notice@xiaominart.com`。没做这一步之前，欢迎邮件不会发出（其余功能不受影响，订阅照常落库）。这是 Resend 平台规则，不是代码问题。

### 2. 关注（RSS）

- 新增 `/rss.xml`（RSS 2.0），收录字游记连载、新作品、节气礼物等精选条目。
- 为什么是 RSS：不依赖第三方平台、任何阅读器和 AI 助手都能直接抓，公众号筹备期间它就是「关注」的真实通道。
- 订阅区已加入口：「不方便留邮箱？用阅读器关注本站更新：RSS 订阅源」。

### 3. 字游记系列内容（已进订阅）

- 订阅区新增「正在连载」卡：字游记 · 第一站十二生肖 + 入口链接。
- 欢迎邮件正文含第一站邀请 + 「下一站动笔时你会比所有人先知道」的钩子。

## 第二期：确认后 2–3 个工作日可上线

| 功能 | 说明 | 为什么需要 |
|---|---|---|
| 双选确认（double opt-in） | 提交后先收确认邮件，点链接才正式入列 | 反垃圾合规（GDPR/国内邮件规范），避免被人恶意填别人邮箱 |
| 一键退订 | 每封邮件底部带带 token 的退订链接，点击即从 `subscribers` 标记退订 | 欢迎邮件「回复退订」只是过渡，规模化后必须自动化 |
| 月度简报模板 | 固定三段：新写好的字 / 字源故事 / 一句带走的话 | 让订阅有稳定预期，也是字游记的连载容器 |

**新增数据字段**：`subscribers` 表加 `status`（active / pending / unsubscribed）+ `token`（退订/确认令牌）+ `confirmed_at`。

## 技术备忘（给未来的助手/开发者）

- 欢迎邮件代码：`functions/api/_lib/notify.ts` 的 `sendSubscriberWelcome()`，由 `functions/api/lead.ts` 订阅分支调用。
