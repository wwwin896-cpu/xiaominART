## 一、这次改了什么

改造前：点「私信」→ 弹出一个表单，要访客填微信/手机号 + 留言 → 进飞书群。
问题：这是**留言板**，不是对话。访客要留联系方式，心理成本高；你也只能被动等。

改造后：点「私信」→ **直接进对话框**，访客不用填任何信息、不用加好友：

| 访客在哪打开网站 | 点「私信」后发生什么 |
|---|---|
| 微信里（朋友圈、聊天分享、公众号） | 直接跳进「微信客服」会话页 —— 原生微信聊天界面，**不用加好友**。你回复后，他的微信聊天列表会有新消息提醒。 |
| 手机浏览器 / 电脑浏览器 / 小红书等 | 网站内弹出聊天面板，不离开页面。你在 Knocket 收件箱或 Telegram 里回。 |
| 两条通道都还没配好时 | 自动回退成原来的留言表单，不会出现「点了没反应」。 |

## 二、你需要做的两件事（各约 30 分钟 / 10 分钟）

### 通道 A：微信客服（微信内用，主力）

2. 管理后台 →「我的企业」→「前往认证」
   - 第三方审核机构收费 **¥300/年**，1–7 个工作日
   - ⚠️ 不认证就用不了微信客服，这是腾讯的硬规则，绕不过
3. 认证通过后 →「应用管理」→「微信客服」→ 开通
   - 基础版免费：10 个客服坐席、每月 1 万次咨询
4. 在里面创建一个客服账号（名字建议就用「小民艺术」）→「获取客服链接」
   - 形如 `https://work.weixin.qq.com/kfid/kfcAbCdEfGhIjKlMn`
   - **把这一整串发给我**

> 微信客服后台还能设：欢迎语、离线自动回复、常见问题自动答。
> 这些先不用管，等链接通了再一项项调。

### 通道 B：Knocket 网页聊天（浏览器用，兜底）

1. 打开 https://knocket.trtc.io/register/ → 邮箱注册（腾讯云 TRTC 出品，**永久免费、无水印**）

## 三、拿到之后要做什么

两条路，选一条：

**方式一（省事）**：把两串发我，我填好、构建、上线，再帮你实测一遍。

**方式二（自己动手）**：打开 `src/data/site.ts` 第 55 / 57 行，把值填进引号里：

```ts
export const chatConfig = {
  wechatKfUrl: 'https://work.weixin.qq.com/kfid/kfc你的客服链接',
  knocketIdentifier: '你的identifier',
};
```

填完提交推送，Cloudflare 会自动构建上线。

> 只想先上一条？可以。只填微信客服 = 微信内能直接聊，其他浏览器走留言表单。
> 只填 Knocket = 全部环境都弹聊天面板。

## 六、已知限制（提前知道，免得后面误会）

- **微信客服在电脑浏览器里**点击会显示二维码，要拿手机扫。这是腾讯的设计，改不了。
  所以浏览器环境我们走 Knocket，不跳微信。
- **Knocket 的聊天记录只在你自己的收件箱里**，访客关掉页面后，除非他留了邮箱，
  否则你回复他看不到。这也是为什么微信内一定要走微信客服。
- 两条通道的**聊天记录不互通**：微信客服的在企业微信后台，Knocket 的在它自己的收件箱。
