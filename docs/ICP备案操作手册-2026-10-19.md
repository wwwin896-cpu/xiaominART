## 0. 先纠正一个关键认知：备案 ≠ 可以开商城

这一条如果不先弄清，备案做完会发现还是不能建商城。

| 项目 | 非经营性 ICP 备案 | 经营性 ICP 许可证 |
|---|---|---|
| 办什么 | 网站**展示信息**（品牌、作品、案例、咨询） | 网站**在线交易**（下单、支付、购物车） |
| 门槛 | 免费，材料齐全即可 | 注册资本 **100 万以上**、社保人数、专项审批，周期数月 |
| 本站现状 | ✅ 符合 | ❌ 不具备 |

**所以：备案通过后，站内仍然不能挂微信支付、不能做购物车。**
成交继续走「咨询 → 微信/小程序下单」，这条路径在站外，不影响备案。

这也是上次建议「商城先别建」的法规依据——不是技术问题，是资质问题。
真要做站内商城，得先办经营性许可证，那是另一个量级的事。

## 2. 买服务器（备案服务号的前提）

阿里云备案要求：服务器在**中国内地**、**包年包月 ≥ 3 个月**、有**公网 IP**。
不买服务器拿不到「备案服务号」，没有服务号无法提交。

**推荐配置**（够用且最省）：

| 项 | 选择 |
|---|---|
| 产品 | 轻量应用服务器（不是 ECS，轻量更便宜） |
| 地域 | **华东1（杭州）** 或 **华东2（上海）**——离南京近，延迟低。不要选香港/海外 |
| 镜像 | Ubuntu 22.04（纯净系统） |
| 配置 | 2 核 2G / 40G SSD / 3M 带宽（最低档即可，纯静态站） |
| 时长 | **1 年**（阿里云常有新用户 1 折活动，约 ¥300–500/年） |

买完在控制台「轻量应用服务器 → 服务器详情 → 备案服务号」点申请，得到一个 6 位服务码。

> 一台服务器可申请 5 个服务号，本站只需 1 个，剩余留着备用。

## 3. 技术迁移（这部分我来做，你不用操作）

### 3.1 要迁什么

| 现状（Cloudflare Pages） | 迁到阿里云后 |
|---|---|
| 静态 HTML（`dist/`，90 页） | nginx 直接托管，零改动 |
| `/api/lead` 表单提交 | **需重写**为 Node 接口 |
| `/api/event` 埋点 | **需重写**为 Node 接口 |
| `/api/progress` 作品进度 | **需重写**为 Node 接口 |
| `/api/keystatic/*` 在线后台 | **需重写**，或暂时停用 |
| `/api/admin/progress` | 同上 |

`functions/` 下 6 个文件依赖 Cloudflare 运行时（`Pages Functions`），换成阿里云后全部失效。
迁移 = 用 Node（Hono/Express）+ pm2 复刻这些路由，**约 1–2 个工作日**。

短期可先只复刻 `/api/lead`（表单，直接关系询盘）与 `/api/event`（埋点），
后台 `/keystatic` 暂用本地编辑 + 推送的方式顶上。

### 3.2 DNS 怎么切

现在 NS 指向 Cloudflare，备案要求域名指向境内服务器。

- **做法**：阿里云控制台把 DNS 改为「阿里云解析」（自动同步），加两条 A 记录指向轻量服务器公网 IP
- **不要删 Cloudflare 项目**——万一备案受阻，改回 NS 即可恢复，5 分钟回滚

### 3.3 备案期间网站要关吗

阿里云规则：「未备案域名不支持提前上线网站并访问」。
实际操作中，江苏不强制关站，但**核验时会访问域名**，要求页面完整、内容与备案填写一致。

本站内容完整（无「建设中」页），**建议不关站，只把备案信息填准**。
若阿里云初审明确要求关站，就临时挂一个「网站备案中」静态页，通过后立即恢复。

### 3.4 迁移前必须导出的 6 个密钥（建议今天就抄）

位置：Cloudflare Dashboard → Workers & Pages → **xiaominart** → Settings → Variables and Secrets

| 变量 | 用途 | 缺失后果 |
|---|---|---|
| **FORMS_ACCESS_KEY** | 表单写库鉴权 | **`/api/lead` 直接 503，询盘全部丢失** |
| FEISHU_WEBHOOK_URL | 新询盘推飞书群 | 没有提醒，只能靠人盯后台 |
| FEISHU_KEYWORD | 飞书机器人关键词 | 推送被拒（当前已存在的 19024 报错即此项） |
| RESEND_API_KEY | 邮件通知 | 无邮件提醒 |
| RESEND_FROM_EMAIL | 发信人地址 | 同上 |
| RESEND_TO_EMAIL | 收件人地址 | 同上 |

> Keystatic 的 4 个值（CLIENT_ID / CLIENT_SECRET / SECRET / APP_SLUG）本地 `.env` 已有，不用抄。
> 上表 6 个**只在 Cloudflare 后台**，本地为空——不导出就等于迁移后表单失效。

## 4. 提交备案（你操作，全程手机 + 阿里云 App）

入口：阿里云控制台 → 搜索「ICP 备案」→ 开始备案

### 4.1 逐字段填写建议

| 字段 | 填什么 | 说明 |
|---|---|---|
| 备案类型 | **首次备案** | 之前没有备案号 |
| 主体性质 | **企业** | |
| 主办单位名称 | 南京宁伊文化传播有限公司 | 与营业执照**一字不差** |
| 证件号码 | 913201025685882797 | |
| 主体负责人 | **朱民** | 江苏管局要求必须是法定代表人，填别人需授权书且大概率驳回 |
| 网站负责人 | 朱民（可直接兼任） | 若换人，必须上传加盖公章的授权书 |
| 网站名称 | **小民艺术** | 4 个汉字、不含行政区划、与「文化传播」经营范围相关。**不要写「小民好礼商城」**——「商城」暗示经营性，直接驳回 |
| 网站服务内容 | **其他**（或「文化艺术」） | **绝不能勾「电子商务/在线交易」**，那是经营性范畴 |
| 网站简介 | 传统文化与书法作品展示、艺术家介绍、定制业务咨询 | 一句话说清「展示 + 咨询」，不要提支付、下单 |
| 域名 | xiaominart.com | 只填主域名，`www` 会自动带上 |
| 服务器 IP | 轻量服务器公网 IP | |
| 备案服务号 | 第 2 步申请的 6 位码 | |

> 网站名称若被退回，备选顺序：① 小民艺术 → ② 宁伊文化 → ③ 小民艺术文化。
> 退回时管局会给理由，按理由改一个再交即可，不影响后续。

### 4.2 要上传的材料

| 材料 | 要求 |
|---|---|
| 营业执照 | 原件扫描/清晰拍照，四角完整、无反光 |
| 法人身份证 | 正反面，同一张图内 |
| 网站负责人身份证 | 若与法人同一人，可复用 |
| **核验单** | 系统生成 PDF → **打印 → 手写签名 + 加盖公章 → 扫描上传**（江苏要求，不能电子签） |
| 人脸核验 | 阿里云 App 内完成，按提示点头/眨眼 |

### 4.3 提交后的时间线

```
D0    提交
D+1   阿里云初审（会打电话，注意接听 95187 开头号码）
D+1   工信部短信核验（6 位码，24 小时内到 beian.miit.gov.cn 输入，超时要重发）
D+2~ 管局审核（江苏平均 12–20 个工作日，快则 3–5 天）
```

**提交后 24 小时内手机会收到工信部短信，务必当天完成核验，否则订单作废。**
