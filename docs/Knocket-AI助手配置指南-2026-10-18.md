# Knocket AI 助手配置指南（2026-10-18）

> 对应后台：AI Agent → 设置（截图里那一页）。填完这个，AI 才能替你回访客的消息。

---

## 一、这页在要什么

Knocket 自己不带大模型，它要你提供一把「兼容 OpenAI 接口」的 API Key，  
AI 才能生成回答。四个格子对应关系：

| 后台格子    | 填什么                              |
| ------- | -------------------------------- |
| 供应商     | 选 **OpenAI**（它允许改下面的 API URL）    |
| API Key | 你在大模型平台申请的密钥（见下）                 |
| API URL | 见下表（**不要**留默认的 openai.com，国内连不上） |
| LLM 模型  | 见下表                              |

填完点「**测试连接**」→ 绿了再点「**保存**」。

## 二、推荐配置：智谱 GLM-4-Flash（免费）

为什么选它：国内注册、手机号就行、**这个模型永久免费**、中文好、有 OpenAI 兼容接口。

1. 打开 <https://open.bigmodel.cn> → 手机号注册登录
2. 右上角头像 →「API 密钥」→ 新建一个，复制（形如 `xxxxxxxx.xxxxxxxx`）
3. 后台四个格子这样填：

| 格子      | 填入                                     |
| ------- | -------------------------------------- |
| 供应商     | OpenAI                                 |
| API Key | 你刚复制的密钥                                |
| API URL | `https://open.bigmodel.cn/api/paas/v4` |
| LLM 模型  | `glm-4-flash`                          |

1. 测试连接 → 保存

### 备选：DeepSeek（效果更好，按量付费，约 ¥1/百万字）

注册 <https://platform.deepseek.com> → 充值 ¥10 起步：

| 格子      | 填入                            |
| ------- | ----------------------------- |
| API Key | DeepSeek 的密钥                  |
| API URL | `https://api.deepseek.com/v1` |
| LLM 模型  | `deepseek-chat`               |

先用免费的 glm-4-flash 跑通，觉得 AI 回答不够好再换这个，填法完全一样。

## 三、保存之后，必做：喂知识库

AI 没有业务知识会乱答。左侧菜单「**知识库**」→ 新建 →  
把下面这段整段粘进去（也可以拆成多条，一条一个主题）：

```text
【品牌介绍】
小民艺术 XIAOMINART 是南京宁伊文化传播有限公司运营的书法艺术品牌，
主营书法作品与书法定制礼品，官网 xiaominart.com。

【能定制什么】
书法作品定制：选字（如「长乐」「观自在」）、题字、落款均可按需求定制；
十二生肖系列：以甲骨文字源为创作起点，作品名如「子鼠开天」「诸事如意」；
节日礼品：四季流转·节日问候系列，适合企业批量赠送。

【价格】
40.5×17.5cm 横幅与 A4 竖幅生肖作品：¥300–500 区间，按内容与字数定价；
其他尺寸（42×22cm、45×45cm 圆光、160×55cm 长卷）单独报价；
企业批量礼品（50 份起）单独报价，支持企业 Logo 定制与增值税专用发票。

【交付周期】
常规定制：25–45 个工作日；具体以需求确认后的排期为准。

【定制流程】
说明需求（送谁、什么场合、想要什么字）→ 确认内容与价格 → 制作 → 寄出。

【售后】
签收后 7 天内可反馈；运费：买家原因退货由买家承担，卖家原因由卖家承担；
定制品同样支持 7 天无理由——书法作品不满意可以重新写。

【联系渠道】
微信：见官网底部「私信」；也可通过官网表单留言，2 个工作日内回复。
```

注意最后一条「联系渠道」里的微信号你后台有了之后自己补上真号，AI 才能告诉客人。

## 四、同页下方的「转人工」

展开看一眼：**建议开启「AI 机器人转人工」**——AI 答不了或客人主动要求时转给你。  
转人工后消息去哪、谁收，取决于「通知」设置（见下）。

## 五、最后：通知（左侧菜单最后一项）

把通知渠道配上（微信/邮件/App，按后台支持的选），  
**确保访客来消息时你手机能收到提醒**。这条没配，前面全部白搭。
