## 一、本阶段完成项

### 1. 三步划分（需求 → 细节 → 联系方式）

把原来的一页长表单（14 个字段平铺）拆成 3 个 `<fieldset>`：

| 步骤 | 名称 | 字段 | 必填 |
|---|---|---|---|
| **01** | 你的想法 / Your intention | `intention`、`inspiration`、`context`、`use` | `intention` |
| **02** | 具体细节 / Details | `size`、`displaySpace`、`displaySpaceOther`、`budget`、`direction`、`artist`、`timeline` | 无 |
| **03** | 联系方式 / How to reach you | `name`、`contact`、`private` | `name`、`contact` |

**为什么联系方式放最后**：让用户先投入表达、再被要求留信息，是表单转化优化的通用做法。
原表单第 1、2 个字段就是「称呼」「联系方式」，用户还没表达任何想法就被要求留信息。

### 2. 进度指示（新增 `FormStepper.astro`）

- 序号圆点 + 中英文标签 + 底部进度条三段式
- `role="progressbar"` + `aria-valuenow`，脚本同步更新
- 已完成 / 当前 / 未达 三态视觉（已完成为朱砂描边、当前为朱砂实心）
- 窄屏（≤640px）隐藏英文与连接线，只留序号 + 中文，避免挤压变形

### 3. 逐步校验（只校验当前步）

- 「下一步」调用 `reportValidity()` —— 用浏览器原生提示与滚动定位，不自己造一套错误 UI
- **只校验当前步**：否则用户在第 1 步点下一步会看到第 3 步的「请填写称呼」报错
- 提交时**再做一次全量兜底**（逐步遍历所有 fieldset），防止用脚本绕过某一步
- 若兜底发现某步有误，自动 `goTo(i)` 跳回去并聚焦到问题字段

### 4. 返回上一步保留数据

不重建 DOM、不 reset，只切换 `hidden` 属性 —— 数据天然保留（已浏览器实测验证）。

### 5. 渐进增强（无 JS 仍可用）

- 三个 fieldset 在 HTML 里，第 2/3 步初始带 `hidden`
- 表单上**不加** `novalidate` → 无 JS 时浏览器原生 `required` 仍会拦住空提交
- 脚本异常时（`else` 分支）**强制显示全部步骤**并解除 `inert`，保证表单始终可用
- 非当前步设 `inert`，键盘用户不会 Tab 进看不见的字段

### 6. 埋点修正（重要）

**原代码的 `consultation_start` 用 `{ once: true }` 挂在 `input` 上** —— 改成三步后，
第 2/3 步的输入**不会再触发**该事件。已改为手动守卫（`startedTracked` 布尔），
语义不变但能跨步骤正常工作。

新增 `consultation_step` 事件（每步点击「下一步」时上报 `{ step, total }`），
用于定位用户卡在哪一步流失。**注意**：该事件名需同步加入
`functions/api/event.ts` 的 `ALLOWED_EVENTS` 白名单，否则会被接口拒绝 —— 见下节。

### 7. 顺带修复：`context=` 带参静默失效（既有缺陷）

全站 8 处 CTA 用 `?context=xxx` 带参，但传的值**几乎都不是 `select` 的真实选项值**：

| 调用处 | 传的值 | 是否为选项值 |
|---|---|---|
| `WishCard.astro` | `主页心意卡` | ❌ |
| `content.ts` ×2 | `礼赠或纪念`、`家居空间` | ❌（选项含「 / Gift or milestone」后缀） |
| `gift-guide` ×2、`gifts`、`help` | `送礼建议` | ❌ |
| `occasions/[slug]`、`recipients/[slug]` | 场合/对象标题 | ❌ |

原生 `select.value = v` 遇到不匹配会**静默落空**，所以这些 CTA 点击后 `context` 一直是空的。

**修法**：`setValue` 对 `<select>` 做兜底 —— 赋值失败时插入一个临时选项
（`data-from-query="1"` 标记），把上下文真正传下去；用户仍可改选其它选项。

> 此缺陷非本次改造引入，是原实现既有问题，顺手一并修掉。
