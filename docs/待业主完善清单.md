## 二、待业主提供 / 决策

### 【P0】必做 —— 不做则 GEO 效果大打折扣

#### 1. ⭐ 微信公众号发布「回答式」文章

**为什么最重要**：腾讯元宝与 ima 的检索**重度依赖微信公众号生态**。
你的官网是「事实源」，但公众号才是元宝/ima **能发现你的路**。

**做法**：标题就用用户会问的话（AI 靠这个匹配问题）

| 建议标题 | 对应 AI 提问 |
| -- | -- |
| 送长辈什么书法礼品好？三种预算的具体推荐 | 「送长辈礼物推荐」 |
| 乔迁礼物送什么有诚意？手写书法的选择思路 | 「乔迁送什么」 |
| 企业答谢礼怎么选不踩雷？定制书法礼品流程与报价 | 「企业礼品定制」 |
| 书画定制要多久？从沟通到交付的完整流程 | 「定制要多久」 |
| 手写书法礼品多少钱？三档价格说清楚 | 「书法礼品价格」 |

**要点**：每篇自然带上 `xiaominart.com`；用小标题 + 分点 + 具体数字；
正文直接回答标题的提问（AI 摘的就是这段）。

> **助手可代做**：如果你提供公众号后台，或愿意把草稿给我，我可以按
> GEO 结构（H2/分点/FAQ/事实数据）帮你写文章初稿。
> **只需你说一声「帮我写公众号文章」。**

#### 2. 抖音 / 头条发内容（豆包的关键）

豆包依托字节生态。发短视频（制作过程、题字含义、送礼场景），
简介/文案里带官网。**频次**：每周 1–2 条即可，重在持续。

#### 3. 知乎回答（跨平台通用，最适合被 AI 引用）

挑这些问题回答（长文最好）：
- 「书法礼品怎么选？」
- 「企业礼品定制哪家好？」
- 「送老师什么礼物合适？」

**为什么知乎有效**：AI 回答决策型问题时，常引用知乎的经验长文。
