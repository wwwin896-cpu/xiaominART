# 埋点事件字典

> 2026-10-07（T-02）建立。此前页面使用了 20+ 种 `data-event` 事件名，但客户端与服务端各有一层只含 6 个事件的白名单，绝大多数事件被静默丢弃，行为数据为空。现将两端白名单扩为全量，本文为唯一字典。
>
> **改动规则**：新增事件时，① 页面加 `data-event="xxx"`；② `src/scripts/cloud-forms.ts` 的 `TRACKED_EVENTS` 加同名项；③ `functions/api/event.ts` 的 `ALLOWED_EVENTS` 加同名项；④ 本文登记。三处缺一，事件依然会被丢弃或丢失语义。

## 上报链路

```
用户点击 [data-event] → Layout.astro 监听 → CustomEvent('xiaominart:event')
→ trackEvent()（客户端 TRACKED_EVENTS 过滤 + 会话内去重）
→ POST /api/event → 服务端 ALLOWED_EVENTS 过滤 → events 表
```

## 事件清单

### 转化入口

| 事件 | 触发位置 | 含义 |
|---|---|---|
| `custom_inquiry_start` | 首页定制入口 | 用户进入定制意图 |
| `custom_entry` | 定制创作页入口卡 | 同上，卡片位 |
| `business_entry` | 企业礼赠入口 | 用户进入 B 端意图 |
| `artist_service_entry` | 艺术家服务入口 | 用户关注艺术家服务 |
| `channel_landing_view` | 渠道专题页 | 渠道落地曝光 |
| `mini_program_click` | 礼品详情页 | 点击「微信小程序下单」 |
| `contact_channel_click` | 联系渠道点击 | 程序化：联系渠道点击 |

### 礼赠线

| 事件 | 触发位置 | 含义 |
|---|---|---|
| `gift_advice_click` | 选礼/礼品页「获取送礼建议」 | 送礼建议意向（高频转化前奏） |
| `gift_guide_view` | 选礼指南 | 指南曝光 |
| `gift_guide_select` | 选礼器选择（程序化） | 用户筛选了场合/对象 |
| `gift_guide_to_detail` | 指南 → 详情 | 从指南进入礼品详情 |
| `gift_guide_to_advice` | 指南 → 建议 | 从指南转入建议 |
| `gift_guide_ready_made` | 指南 → 现货 | 从指南看现货 |
| `gift_detail_view` | 礼品详情曝光 | 详情页到达 |
| `ready_work_click` | 现货详情「咨询这一幅」 | 现货咨询意向（核心 P0 事件） |
| `scene_to_product` | 灵感页 → 商品 | 场景种草转化 |
| `scene_view` | 首页场景卡点击 | 场景卡曝光点击 |
