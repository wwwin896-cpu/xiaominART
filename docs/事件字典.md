# 埋点事件字典

> 2026-10-07（T-02）建立。此前页面使用了 20+ 种 `data-event` 事件名，但客户端与服务端各有一层只含 6 个事件的白名单，绝大多数事件被静默丢弃，行为数据为空。现将两端白名单扩为全量，本文为唯一字典。
>
> **改动规则**：新增事件时，① 页面加 `data-event="xxx"`；② `src/scripts/cloud-forms.ts` 的 `TRACKED_EVENTS` 加同名项；③ `functions/api/event.ts` 的 `ALLOWED_EVENTS` 加同名项；④ 本文登记。三处缺一，事件依然会被丢弃或丢失语义。

## 上报链路

```
用户点击 [data-event] → Layout.astro 监听 → CustomEvent('xiaominart:event')
→ trackEvent()（客户端 TRACKED_EVENTS 过滤 + 会话内去重）
→ POST /api/event → 服务端 ALLOWED_EVENTS 过滤 → events 表
```

| `custom_inquiry_start` | 首页定制入口 | 用户进入定制意图 |

| `business_entry` | 企业礼赠入口 | 用户进入 B 端意图 |
