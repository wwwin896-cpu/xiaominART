# 密钥轮换与安全头操作说明

> 2026-10-06 ｜ 对应 commit `dbb8c8a` / `49f1f7b` / `cab8f82`
> 本文只写需要业主手动完成的部分。代码侧已全部改完并上线。

## 一、为什么要换密钥（必做，优先级最高）

`functions/api/lead.ts` 与 `functions/api/event.ts` 原本把云数据库访问密钥
`wbpk_F0w7…` 直接写在源码里。仓库是公开的，等于这把钥匙已经公开。

代码侧已改成从环境变量 `FORMS_ACCESS_KEY` 读取，源码里不再有任何密钥。
但**密钥值本身需要作废并换新**——这一步只能由业主操作。

## 二、操作步骤

### 第 1 步：作废旧密钥

到 WorkBuddy 云服务（`xiaominart-forms`）的控制台，找到访问密钥管理，
把以 `wbpk_F0w7` 开头的那把**作废/删除**。
（作废后网站表单会短暂不可用，属正常——第 3 步配好即恢复。）

### 第 2 步：生成新密钥

在同一处新建一把访问密钥，复制新值（形如 `wbpk_xxxxxxxx…`）。
新密钥只显示一次，请先粘到临时记事本里。

### 第 3 步：写入 Cloudflare 环境变量

1. 打开 Cloudflare Dashboard → **Workers & Pages** → 项目 **xiaominart**
2. **Settings** → **Variables and Secrets** → **Add**
3. 填写：
   - **名称（Variable name）**：`FORMS_ACCESS_KEY`（必须完全一致，区分大小写）
   - **值（Value）**：粘贴第 2 步的新密钥
   - **类型**：选 **Secret**（加密存储，之后无法回看）
4. 环境（Environment）至少勾选 **Production**；有 Preview 环境也一并勾上
5. 保存后**重新部署一次**（推送任意提交，或在 Deployments 里 Retry 最近一次），
   环境变量才会被 Functions 读到

### 第 4 步：验证

在本机终端执行（把域名换成正式域名）：

```bash
curl -s -o /dev/null -D - -X POST https://xiaominart.com/api/lead \
  -H "Content-Type: application/json" -d '{}'
```

- 看到 **HTTP 503** → 变量没读到，回到第 3 步检查变量名与「重新部署」
- 看到 **HTTP 400** 且 body 是「未知表单类型/请填写称呼和联系方式」→ 配置成功

再用页面上的定制表单真实提交一次，确认能收到记录。

## 三、安全响应头现状（已完成，无需操作）

线上 `https://xiaominart.com` 现在返回：

| 响应头 | 值 | 作用 |
|---|---|---|
| `X-Frame-Options` | `DENY` | 防止被第三方 iframe 嵌套（点击劫持） |
| `X-Content-Type-Options` | `nosniff` | 禁止浏览器猜测文件类型 |
| `Referrer-Policy` | `strict-origin-when-cross-origin` | 跨站跳转不泄露完整路径 |
| `Permissions-Policy` | 关闭摄像头/麦克风/定位/支付 | 页面用不到这些权限 |
| `Content-Security-Policy-Report-Only` | 全站 `'self'` | **观察期**：只报告不拦截 |
| `/api/*` 额外 | `Cache-Control: no-store`、`X-Robots-Tag: noindex` | 接口不缓存不被收录 |

### CSP 从观察期转为正式启用

观察一到两周，用浏览器开发者工具（Console 面板）翻几个主要页面，
确认没有 `Content-Security-Policy-Report-Only` 开头的违规告警，然后：

把 `public/_headers` 里的
`Content-Security-Policy-Report-Only:` 改成 `Content-Security-Policy:` 即可。

## 四、两个已踩过的坑（写进配置注释，避免复发）

1. **同一 path 规则只能出现一次。** `_headers` 里重复写两段 `/*`，
   后者会整体覆盖前者而非合并——`X-Frame-Options` 曾因此静默失效。
   要加头就往同一个 `/*` 段里加。

2. **绝不在 `/*` 段里加 `X-Robots-Tag`。** `/*` 是通配段，一旦设成
   `noindex, nofollow`，整站都会被搜索引擎排除，与收录目标完全相反。
   接口类的 noindex 只在 `functions/api/*.ts` 代码内单独设置。
