# xiaominART 首页品牌厚度与导航承接建议

日期：2026-09-29

## 一、总判断

当前首页已经具备较好的东方审美、留白和情绪氛围，但它更像一页“定制创作品牌展示页”，还没有完整承担一个品牌主页应该承担的五个任务：

1. 让第一次访问的人在 5–10 秒内明白 xiaominART 是什么；
2. 让用户知道两位艺术家分别能为他做什么；
3. 让用户感受到品牌的文化厚度、手艺和品质依据；
4. 让不同意图的用户找到正确入口，而不是所有人都被推向同一个定制表单；
5. 让用户愿意继续浏览，在首页与导航页之间形成自然的内容路径。

建议把首页从“作品与定制的情绪展示页”升级为：

> **东方文化创作品牌的总入口：先建立气质认同，再展示手艺证据，最后让用户选择自己的路径。**

核心结构建议：

```text
品牌第一印象
→ 这是谁 / 能做什么
→ 两位艺术家
→ 两条业务线
→ 手艺与文化证据
→ 作品与礼物
→ 机构合作
→ 用户选择入口
→ 轻量咨询
```

## 二、当前线上首页的主要问题

### 1. 有气质，但品牌业务说明不够清楚

当前首屏使用“方寸之境，也藏山河”等诗性表达，适合建立氛围，但第一屏没有直接说清：

- xiaominART 是什么品牌；
- 有哪两位艺术家；
- 书法小品、非遗面塑、插画和机构服务之间是什么关系；
- 用户可以购买现成作品、定制作品，还是发起机构合作。

建议保留诗性主标题，但在首屏标题下增加一条事实型说明：

> 小民艺术，由升斗小民与非遗小宁共同创作：手写书法、非遗面塑、插画与文化项目，让东方文化进入礼物、空间与日常。

### 2. 两位艺术家没有成为首页的核心识别入口

当前首页主要让用户看到“作品”和“定制流程”，但还没有让用户快速认识：

- 升斗小民：手写书法、字游记、古文启蒙；
- 非遗小宁：非遗面塑、插画、博物馆文创、微缩场景。

这会削弱品牌最重要的差异化资产：不是一个抽象的“艺术定制平台”，而是两位有真实经历、不同手艺和不同叙事能力的创作者。

建议在首页首屏之后设置“双创始人入口”，每位艺术家各有：

- 肖像或工作状态图；
- 一句话定位；
- 主要媒介；
- 适合的业务；
- 进入个人页面的按钮。

### 3. 业务线混在一起，用户容易不知道从哪里开始

当前首页的“心意之选”“定制故事”“共创过程”整体偏向定制委托，没有清晰区分：

- 个人 / 礼赠用户；
- 想购买手写现货的用户；
- 想做定制手写的用户；
- 出版社、博物馆、学校、企业等机构客户。

建议设置清晰但不喧闹的业务分流：

```text
为自己或一个人
手写现货 · 定制手写 · 雅礼

为一家机构或一场活动
出版社插画 · 博物馆文创 · 非遗面塑活动 · 企业礼赠
```

### 4. 旧内容与新业务方向存在冲突

线上当前仍能看到一些需要尽快处理的旧信息：

- 首页存在“灵感源自真实故事”一类未必有授权依据的文案；
- `/about/` 仍有“不卖现货”的旧定位；
- `/shop/` 返回 404；
- 企业礼赠页仍提示表单只是本机生成草稿、无法真正进入后台；
- 部分页面使用“书画礼品定制”作为总称，但新业务已扩展到面塑、插画和博物馆项目。

这些问题会影响用户对品牌成熟度和交易可靠性的判断，应优先修正。

### 5. 首页内容区块之间缺少“继续浏览理由”

现在首页的内容是连续向下阅读，但各区块之间的链接动机还不够强。用户看完一个区块后，不一定知道下一步为什么要点击导航。

建议每个区块只承担一个明确任务，并给出“下一步探索”：

- 看完品牌介绍 → 认识两位艺术家；
- 看完艺术家 → 看她们分别能做什么；
- 看完业务线 → 查看作品、礼物或机构合作；
- 看完作品 → 进入场合、对象或定制流程；
- 看完机构服务 → 查看合作方式与提交需求。

## 三、推荐的首页信息架构

### 区块 1：品牌首屏

目标：建立气质，同时在 5–10 秒内说明品牌事实。

建议内容：

- 视觉主标题：保留“方寸之境，也藏山河”一类具有记忆点的品牌句；
- 事实副标题：

> 两位艺术家，四种文化媒介：手写书法、非遗面塑、插画与空间叙事。

- 两个主入口：
  - 看雅礼与手写作品；
  - 看机构合作与文化项目。
- 一个弱入口：认识两位艺术家。

不要在首屏放大量价格、促销、购物车或复杂表单。品牌首屏首先承担认知任务。

### 区块 2：一句话说明“我们可以为你做什么”

建议用 4 个简短能力模块，而不是堆长段落：

| 能力 | 说明 | 入口 |
|---|---|---|
| 手写现货 | 已完成的书法小品，适合直接选择 | `/shop/` |
| 定制手写 | 从一句话、一个人或一个场合开始创作 | `/custom-commission/` |
| 非遗面塑与插画 | 适合活动、文创、故事与文化传播 | `/artists/xiaoning/` |
| 机构合作 | 出版社、博物馆、学校、企业与文化项目 | `/partners/` |

### 区块 3：两位艺术家

建议标题：

> 两双手，两种进入文化的方式。

升斗小民卡片：

> 从一个字的来处，走回文化与人的内心。手写书法、字游记、古文启蒙与定制表达。

非遗小宁卡片：

> 把故事捏成形，把历史带回今天。非遗面塑、儿童插画、博物馆文创与微缩场景。

此区块的作用不是介绍简历，而是让用户知道“下一步应该去看谁”。

### 区块 4：两条业务路径

建议用明显不同但仍统一的两张大卡片：

#### A：个人与雅礼

> 给自己、给一个人，或给一段值得记住的关系。

包含：

- 手写现货；
- 定制手写；
- 24 节气与中国传统节日；
- 生日心意、乔迁之喜、开业贺礼、节日问候、感谢师恩、周年纪念；
- 包装和手写贺卡。

入口：

- 看手写现货；
- 进入选礼指南；
- 发起定制手写。

#### B：机构与文化项目

> 为一家机构、一场活动或一段历史，找到合适的表达方式。

包含：

- 出版社插画；
- 博物馆与文旅图文项目；
- 非遗面塑活动；
- 文创产品；
- 历史场景手绘与微缩还原；
- 企业礼赠。

入口：

- 看机构合作；
- 看服务类型；
- 提交机构需求。

### 区块 5：品质与文化厚度证据

品牌厚度不能只靠散文表达，需要让用户看到“为什么值得信任”。建议设置“我们如何创作”证据区，包含：

1. 书写过程：纸、墨、落笔、停顿和装裱；
2. 面塑过程：材料、捏塑、细节和保存；
3. 插画过程：研究、草图、人物与场景；
4. 博物馆 / 文创过程：资料、讲述、手绘和还原；
5. 包装与交付：作品如何抵达用户手中。

每项都链接到对应文章或艺术家页面，让用户继续浏览，而不是只看一段口号。

不建议使用没有来源的“客户数量”“媒体报道”“合作机构 Logo 墙”。真实授权资料成熟后再添加。

### 区块 6：作品与雅礼精选

这个区块要同时满足品牌审美和移动端浏览：

- 只展示已发布且信息完整的作品；
- 每张卡片有作品名、艺术家、媒介、适合场合和价格 / 询价状态；
- 现货和定制必须有明确标签；
- 不把同一件作品复制到多个栏目中。

建议入口：

- 看全部手写现货；
- 按场合选礼；
- 按对象选礼；
- 看定制手写。

故事顺序应保持：

```text
作品由来 → 适合谁 / 什么场景 → 材质与交付 → 价格或咨询
```

### 区块 7：机构合作精选

首页只展示 3–4 个业务方向，不要把所有服务堆成一张长表：

- 出版社插画；
- 博物馆与文旅；
- 非遗面塑活动；
- 企业礼赠。

每张卡片只回答三件事：

- 做什么；
- 适合谁；
- 如何开始。

案例资料不足时，使用“服务方向”而不是“客户案例”，不要写成已经完成的项目背书。

### 区块 8：情绪价值与表达空间

这是 xiaominART 与普通商品网站最重要的差异。

可以设置一个轻量的“给这份心意一句话”模块：

> 如果这件作品替你留下一句话，你想写什么？

提供非强制的三种入口：

- 为自己留一句话；
- 为一个人写一句话；
- 为一家机构说清楚想表达什么。

这不是立即提交的复杂表单，而是一个情绪入口。点击后进入对应的礼物建议、定制手写或机构需求页。

### 区块 9：最终承接

底部不建议继续使用泛化的“与我们聊聊”作为唯一 CTA。建议根据用户意图提供三个选项：

- 看手写现货；
- 发起定制手写；
- 提交机构合作需求。

旁边保留一段克制说明：

> 不必先懂艺术。告诉我们你想为谁、为哪里或为哪段记忆留下什么，我们会从合适的方向开始回应。

## 四、推荐导航结构

```text
机构合作
```

## 五、让用户停留更久的内容机制

### 1. 每个区块都要有“下一步探索”

首页不是信息终点。每个区块后面要有一个和当前内容相关的下一步：

```text
艺术家 → 看她的作品 / 服务
作品 → 看场合 / 看工艺
工艺 → 看文章 / 看过程
文章 → 看相关作品
作品或礼物 → 进入咨询或小程序
```

### 2. 建立“作品—人物—工艺—场景”的内链闭环

例如一件手写小品详情页可以链接：

- 升斗小民艺术家页；
- 书写过程文章；
- 生日或乔迁选礼页；
- 定制手写页。

非遗面塑内容可以链接：

- 非遗小宁页面；
- 面塑活动页；
- 博物馆与文旅合作页；
- 相关历史故事文章。

### 3. 内容不要只做“展示”，要做“选择辅助”

用户停留时间长不是因为页面越长越好，而是因为每一段都帮助他做了一个判断：

- 我喜欢谁的表达？
- 我需要现货还是定制？
- 我适合哪类作品？
- 这个礼物适合什么关系？
- 这个项目是否适合机构合作？

### 4. 让移动端以“沉浸浏览”开始，以“随时成交”结束

移动端打开默认仍应是品牌首页，而不是商品瀑布流。建议：

- 首屏保留品牌气质；
- 首屏下方快速出现“个人 / 机构”分流；
- 底部固定导航只保留：首页、手写现货、定制手写、联系；
- 机构合作在首页显性出现，并在抽屉菜单中独立展示；
- 商品详情底部再提供小程序购买 / 咨询，不在首页强推购买。

## 六、后台内容模型建议

首页内容必须由后台维护，但不建议把首页做成无限自由的页面编辑器。建议采用“受控区块 + 可排序”模式。

首页可管理区块：

1. Hero 品牌首屏；
2. 能力四项；
3. 艺术家双卡；
4. 两条业务路径；
5. 工艺证据；
6. 雅礼精选；
7. 机构合作精选；
8. 情绪表达入口；
9. 最终 CTA。

后台需要可编辑：

- 标题和副标题；
- 图片及 `alt` 文本；
- 区块顺序；
- 是否发布；
- CTA 文案和 URL；
- 关联产品、艺术家、文章和服务；
- SEO title、description、OG 图；
- 现货 / 定制状态；
- 小程序链接与状态。

每个内容对象至少需要：

```text
slug
中文标题
英文辅助标题（可选）
摘要
正文
封面图
图片 alt
发布状态
SEO 标题
SEO 描述
关联艺术家
关联场合 / 对象 / 媒介
更新时间
```

## 七、需要优先修复的内容和页面问题

### P0：先消除品牌与业务冲突

1. `/shop/` 不再返回 404，应建立手写现货入口；
2. 删除或改写“完全不卖现货”的旧文案；
3. 删除未经授权的“真实故事”表述，改为“方向示例”或补充真实授权资料；
4. 企业表单不能继续提示“只在本机生成草稿”，必须接入可靠收件方式，或明确显示当前未开放提交；
5. 全站“书画礼品定制”改为能覆盖两位艺术家的品牌说明；
6. 关于页加入升斗小民与非遗小宁的正式介绍。

### P1：建立品牌深度

1. 两位艺术家页面；
2. 手写书法内容页；
3. 非遗面塑与插画内容页；
4. 书写、面塑、插画、博物馆项目的过程文章；
5. 机构合作四个服务页；
6. 真实图片和授权案例。

### P2：建立数据闭环

记录但不收集过度个人信息：

- 首页品牌浏览；
- 艺术家卡片点击；
- 手写现货点击；
- 定制手写点击；
- 机构合作点击；
- 选礼筛选；
- 小程序跳转；
- 咨询开始与提交。

## 八、最终建议

首页不应该努力把所有内容一次讲完，而应该完成三件事：

1. **让用户相信这里有真实的人、真实的手艺和真实的文化积累；**
2. **让用户快速找到适合自己的业务路径；**
3. **让每一次浏览都自然通向下一页，而不是停在一段漂亮但封闭的文案上。**

最建议采用的首页主线是：

```text
方寸之境，也藏山河
↓
两位艺术家，四种文化媒介
↓
为个人 / 为机构
↓
手写现货 / 定制手写 / 非遗面塑 / 插画与文化项目
↓
看见创作过程与品质依据
↓
浏览作品与服务
↓
选择场合、对象或合作方向
↓
进入小程序、定制咨询或机构需求
```

这条路径既保留 xiaominART 的温润、克制和文化感，也让首页真正具备品牌入口、内容中心和业务分流中心的功能。
