# xiaominART 首页最终内容与导航汇总方案

日期：2026-09-29

## 一、此次确认的总体方向

本轮首页不再追求一次性展示所有业务，而是通过两段沉浸式创作内容，先让用户看见并感受到两位艺术家的手艺，再逐步进入作品、服务、选礼和咨询。

首页叙事顺序确定为：

```text
品牌首屏三组滚动画面
→ 升斗小民 5 秒动态书写
→ 书法从历史进入现代生活
→ 三张书法品质细节滚动图
→ 非遗小宁 5 秒面塑创作
→ 非遗面塑的情绪价值
→ 三张面塑作品与细节滚动图
→ 我们可以为你做什么
→ 创作过程与品质证据
→ 作品精选
→ 给这份心意一句话
→ 最终咨询入口
```

这套顺序的核心不是“先卖货”，而是：

> **先让用户看见手艺，再让用户理解价值，最后让用户选择适合自己的方式。**

## 二、导航原则

### 本轮确认

顶部导航栏维持当前网站结构不变，不因为首页内容重构而重新命名、拆分或增加一级菜单。

本次只调整：

- 首页内部的内容顺序；
- “手写现货”页面内部的四个主题分类；
- 首页区块与现有导航页面之间的承接关系；
- 后台内容模型和关联字段。

## 三、首页完整区块方案

## 01 / 品牌首屏：三组滚动画面

### 目标

首屏负责建立品牌气质和第一印象，不立即进入商品瀑布流，也不在首屏堆叠复杂业务说明。

### 三组画面建议

#### 画面一：方寸之境，也藏山河

- 重点：品牌气质、东方留白、纸墨与生活空间；
- 画面：真实书房、茶席、纸本或书法局部；
- 文案：保留品牌诗性表达；
- 用户感受：安静、克制、值得停留。

#### 画面二：它不完美，却很真实

- 重点：手写痕迹、纸张纤维、墨色浓淡和手作的不规则；
- 画面：墨迹、纸边、手部、装裱或作品细节；
- 用户感受：不是批量印刷，而是有人亲手完成。

#### 画面三：看似条条框框，实则分寸有序

- 重点：古文字、字游记、书写秩序与当代生活；
- 画面：古文字资料、书写过程、作品局部与现代空间并置；
- 用户感受：小民艺术有文化根基，也能进入今天的生活。

### 首屏信息补充

在诗性主标题下增加一条事实说明，避免用户只感到氛围却不知道品牌能做什么：

> 小民艺术，由升斗小民与非遗小宁共同创作，让书写、面塑与东方文化进入礼物、空间与日常。

首屏主入口仍然克制，建议只保留：

- 看手写作品；
- 认识两位艺术家。

机构合作入口可以在下一段出现，不在首屏制造过多选择。

## 02 / 升斗小民：5 秒动态书写镜头

### 目标

让用户在最短时间内直观看到：

- xiaominART 有真正的手写书法作品；
- 作品由人亲手完成；
- 书法不是抽象概念，而是一种有过程、有呼吸、有情绪的艺术表达。

### 建议镜头节奏

总时长约 5 秒，默认静音、自动播放、循环一次后暂停或低频循环：

```text
0.0–1.2 秒：手、笔、墨与纸进入画面
1.2–3.6 秒：笔锋运行，字形逐渐形成
3.6–5.0 秒：落笔停顿，露出作品局部和纸面细节
```

不建议使用过快剪辑、商业促销文字或音乐轰炸。应保留：

- 笔锋与纸面接触的细节；
- 墨色变化；
- 手腕和呼吸的节奏；
- 真实的纸张与环境声音（如使用声音，必须默认静音并提供开启方式）。

### 视频旁文案

> 一笔落下之前，先听见一句话。  
> 升斗小民从文字的来处出发，把书写带回今天的生活。

辅助入口：

- 进入升斗小民；
- 查看手写现货；
- 了解定制手写。

### 移动端

- 视频宽度占满内容区；
- 高度控制在一屏可读范围内；
- 自动播放必须静音；
- 提供 poster 图片作为加载和不支持视频时的降级；
- `prefers-reduced-motion` 用户显示静态首帧；
- 不让视频阻塞首屏最大内容渲染。

## 03 / 书法从历史进入现代生活

### 目标

把书法从“作品展示”推进到“文化理解”，让用户知道为什么一件手写作品值得被保留、赠送或放入空间。

### 建议表达

> 汉字从生活中来，书写也应该回到生活中去。  
> 从古文字的形与意，到今天案头、书房、茶室和礼物中的一笔，文字一直在替我们保存观察、关系与心愿。

内容不应写成学术论文，而要通过三个具体问题让用户进入：

1. 这个字最初在表达什么？
2. 为什么这句话适合被写下来？
3. 它进入今天的生活后，可以陪伴谁、哪一处空间或哪个时刻？

建议设置三个可点击的内容入口：

- 字游记：一个字的来处；
- 书写过程：一笔如何完成；
- 进入生活：作品如何成为礼物与空间的一部分。

## 04 / 书法品质细节：三张滚动图片

### 目标

不用大量图片，也不用夸张认证，用三张有信息密度的细节图证明品质。

### 三张图的分工

#### 图一：笔墨细节

展示：

- 笔锋起收；
- 墨色浓淡；
- 纸面纤维；
- 手写的不规则和呼吸感。

#### 图二：作品与空间

展示：

- 作品进入书房、茶室、玄关或案头；
- 与木、纸、陶、茶具等真实生活材料的关系；
- 作品尺度与空间比例。

#### 图三：礼物如何抵达

展示：

- 包装盒；
- 手写贺卡；
- 装裱或保护方式；
- 收到作品时的完整感。

### 滚动交互

- 桌面端：三张横向卡片或轻微横向滚动；
- 移动端：单张卡片横向滑动，显示下一张部分边缘；
- 每张图片只配一句说明；
- 点击进入对应作品、包装说明或手写定制页面。

## 05 / 非遗小宁：5 秒面塑创作镜头

### 目标

让用户迅速理解面塑不是静态摆件，而是：

- 有材料触感的手工艺；
- 可以承载人物和故事的造型艺术；
- 可以进入儿童、博物馆、机构活动与文化传播的表达方式。

### 建议镜头节奏

```text
0.0–1.2 秒：面团、工具与手部进入画面
1.2–3.6 秒：人物或场景从材料中逐渐成形
3.6–5.0 秒：完成局部、表情、服饰或场景细节
```

重点不是展示“做得多快”，而是让用户感到：

- 材料是有温度的；
- 形象是被一点点捏出来的；
- 面塑可以讲故事，也可以让人参与。

### 视频旁文案

> 把故事捏成形，把历史带回今天。  
> 非遗小宁从插画、讲述与面塑出发，让传统手艺变得可见、可亲近。

入口：

- 认识非遗小宁；
- 查看非遗面塑；
- 查看机构合作。

## 06 / 面塑作品与细节：三张滚动图片

### 三张图的分工

#### 图一：人物与故事

展示面塑人物的表情、姿态、服饰和故事来源。

#### 图二：手工细节

展示捏塑痕迹、造型层次、颜色和局部细节。

#### 图三：场景与文化还原

展示人物与建筑、器物、展陈或微缩场景的关系。

### 情绪价值表达

配文不强调“可爱”或“好玩”作为唯一卖点，而强调：

- 亲手参与一段文化记忆；
- 让儿童通过触摸理解故事；
- 让博物馆内容拥有更亲近的入口；
- 让机构活动留下可带走、可继续讲述的作品。

## 07 / 我们可以为你做什么

两位艺术家的内容展示完成后，再进入业务解释区。

建议使用四个能力入口：

| 能力 | 说明 | 入口 |
|---|---|---|
| 手写现货 | 已完成的书法小品，按四个主题浏览 | 手写现货 |
| 定制手写 | 从一句话、一个人或一个场合开始 | 定制手写 |
| 非遗面塑与插画 | 适合故事、文创、活动与文化传播 | 非遗小宁 |
| 机构合作 | 出版社、博物馆、学校、企业与活动项目 | 机构合作 |

这个区块必须使用“能为你做什么”的语言，而不是只列艺术媒介。

## 08 / 创作过程与品质证据

建议不再使用只有抽象词语的流程区，而是把两位艺术家的过程分别说明。

### 手写书法

```text
听见一句话
→ 了解关系与场景
→ 选择字形、尺度与纸墨
→ 书写并确认
→ 包装与抵达
```

### 非遗面塑 / 插画

```text
理解故事或项目目标
→ 查找资料与提炼形象
→ 手绘 / 捏塑 / 场景还原
→ 确认展示与活动方式
→ 交付作品或执行项目
```

### 品质证据标签

- 手写过程可见；
- 材料与交付边界提前说明；
- 作品与包装分别展示；
- 机构项目按目标、规模和交付内容沟通；
- 客户案例和图像获得授权后公开。

## 10 / 给这份心意一句话

这是首页情绪价值的核心互动，不做成复杂问卷。

### 建议文案

> 如果这份作品替你留下一句话，你想写什么？

提供三个选择：

- 为自己；
- 为一个人；
- 为一家机构或一场活动。

选择后进入对应路径：

```text
为自己 → 手写现货 / 认识升斗小民
为一个人 → 选礼指南 / 定制手写
为机构或活动 → 机构合作
```

这一区块可以先做轻量跳转，后续再接入咨询表单，不要一开始就要求用户填写大量信息。

## 11 / 最终咨询入口

底部 CTA 根据用户意图提供三个入口：

- 看手写现货；
- 发起定制手写；
- 提交机构合作需求。

辅助说明：

> 不必先懂艺术。告诉我们你想为谁、为哪里或为哪段记忆留下什么，我们会从合适的方向开始回应。

## 五、移动端呈现原则

移动端不是打开即购物页，而是保持品牌沉浸，再提供成交出口。

### 移动端顺序

```text
首屏三组滚动图
→ 手写 5 秒镜头
→ 书法三图横滑
→ 面塑 5 秒镜头
→ 面塑三图横滑
→ 能力入口
→ 作品精选
→ 一句话互动
→ 联系 / 小程序 / 定制
```

### 移动端硬性要求

- 视频默认静音；
- 视频有静态 poster 降级；
- 三图采用横向滑动，不堆成长瀑布；
- 首屏和视频之间避免多个按钮；
- 作品卡片必须显示现货 / 定制状态；
- 底部操作栏不增加与当前导航重复的入口；
- 不在首页直接自动跳转购物页面；
- 触摸区域至少满足移动端可操作尺寸；
- 支持 `prefers-reduced-motion`；
- 图片和视频懒加载，避免影响首屏速度。
