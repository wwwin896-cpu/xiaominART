## 一、全局技术约定

| 项      | 约定                                                                                                                             |
| ------ | ------------------------------------------------------------------------------------------------------------------------------ |
| 仓库     | `C:/Users/andmi/AccioWork/2026-09-14-16-47-30-053-d9decfe5/xiaominart-site`                                                    |
| 线上     | <https://xiaominart.com> （Cloudflare Pages，push 到 main 自动部署）                                                                   |
| 构建     | `NODE_OPTIONS="" npm run build` —— **必须清空 NODE_OPTIONS**，否则 safe-delete shim 会拦截 Astro 清理 `dist/.prerender` 导致 exit=1          |
| 类型检查   | `npx astro check` → 期望 **0 error**（输出为 GBK，需 `iconv -f GBK -t UTF-8`）                                                          |

| 样式作用域  | **父页面 scoped 样式以 `img` 结尾的选择器对 `<Pic>` 渲染的元素失效**，必须写 `:global(img)`                                                            |
| 内容层    | Keystatic 以 `.yaml` 落盘；读取走 `import.meta.glob('...*.yaml',{eager:true,query:'?raw'})` + `yaml.parse`                            |
| 两套商品体系 | ① 现货十二幅 = `src/data/content.ts` 的 `readyMadeWorks`（**页面不要直接 import**，用 `src/lib/ready-made.ts`）；② 礼品 = Keystatic `products` 集合 |
| 客户故事门禁 | `src/lib/stories.ts` 只返回 `authorization && published` 双 true 的条目                                                               |
| 视觉基调   | 法宋 + 中古风 + 金石气；莫兰迪奶油底、黑胡桃木极窄圆角、朱砂印鉴红、衬线体。**禁止默认 UI 样式**                                                                        |
| 敏感信息   | Webhook URL / API Key 一律走 Cloudflare Pages 环境变量，**不得入库**                                                                       |
| 提交粒度   | **同一文件同日只提交一次**（Meemoo 按文件 churn 计分，2026-10-08 已因此扣分）                                                                          |

## 四、验收总则（DoD）

1. **视觉一致性**：严格遵循法宋 + 中古风 + 金石气韵；莫兰迪奶油底、黑胡桃木极窄圆角、朱砂印鉴红、衬线体。禁止粗糙默认 UI。
2. **移动端优先**：iOS Safari / Android Chrome / 微信内置浏览器**真机回归**，无横向溢出与操作遮挡。
3. **零硬编码敏感信息**：Webhook URL、API Key 走 Cloudflare Pages 环境变量。  
   **注意**：本项目为单一 main 分支工作流，原规范要求的 `feature/WO-xx` 分支策略  
   **不适用**（Cloudflare Pages 按 main 部署，PR 流程需另配预览环境）。
4. **每轮必过**：`astro check` 0 error → 构建 exit=0 → sitemap 对齐 → 线上回归 → Meemoo 重扫。
5. **不制造新 churn**：同一文件同日只提交一次；提交信息写清「改了什么 + 为什么」。
