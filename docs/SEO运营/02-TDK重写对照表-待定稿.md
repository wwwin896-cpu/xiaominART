## 三、description 写作模板（给业主自己补其他页用）

```
[是什么] + [送给谁 / 什么场合] + [凭什么不同] + [价格带] + [下一步动作]
```

**示范**：

> 手写书法礼品，适合送老师、长辈与合作伙伴。每件亲笔书写并附释读说明，¥300 起。看看别人怎么选 →

**三条禁忌**：

1. 不要写「在喧嚣之外」「方寸藏境」这类只有品牌内部才懂的话 —— 搜索摘要里没人看得懂；
2. 不要写「欢迎咨询」这种空句，占字数不带来点击；
3. 不要堆关键词（「书法礼品 手写书法 书画定制 礼品定制」），百度会判为堆砌。

## 四、定稿后的执行方式

业主在本文档上直接批注「1✅ 3改xx」即可，我会：

1. 一次性改完所有页面的 `title` / `description`（都在各页 `<Layout title=... description=...>` 处）；
2. 跑 `astro check` + `npm run build` + `check-sitemap`；
3. 线上逐页核对 title/description 是否真的变了（不是看代码，是 curl 线上）。
