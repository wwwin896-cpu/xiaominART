## 零、先对齐概念：SEO / GEO / MTO 到底差在哪

三件事常被混着说，但**做错阶段的代价很大**。用一句话分别定性：

| 阶段 | 用户在做什么 | 你要赢的是什么 | 网站该长成什么样 | 本站现状 |
|---|---|---|---|---|
| **SEO**（现在·基础） | 在百度/Google 输入关键词，从 10 条蓝链里挑一个点进去 | **关键词排名 + 被收录** | 标题含用户搜索词、结构可被爬、加载快、有权重 | **地基不牢**，见第一章 |
| **GEO**（现在·已起步） | 问 AI「送老师什么礼物有文化感」，AI 综合生成答案并给出处 | **被 AI 引用** | 结构化、事实明确、可摘抄、实体清晰 | 已有 `llms.txt` + 实体图谱 + 爬虫放行，**领先多数同行** |
| **MTO**（将来） | 让 AI Agent 代为执行采购（比价、下单、预约） | **被 Agent 选中并可执行** | 机器可读的规格/价格/库存/交期、结构化 API | 有 Product schema（仅现货栏），**尚未成体系** |

**三者的关系不是替代，是叠加。** 没有 SEO 的收录，GEO 就没有可检索的原料；没有 GEO 的实体清晰度，MTO 就没有可信的商品数据。所以**顺序不能跳**：今天先把 SEO 地基补起来，同时不破坏已有的 GEO 资产。

> ⚠️ **本站最需要纠正的一个认知**：
> 过去几轮优化偏向「文案更有格调」（`方寸藏境，山河入章`、`作品档案`、`灵感参考`）。
> 这些对**品牌**是对的，对**搜索**是负分 —— 因为**没有人会在百度里搜「方寸藏境」**。
> 格调留给正文，**标题必须说人话**。这是本文档最重要的一条原则。

## 二、SEO 目标与策略总纲（短 / 中 / 长期）

### 2.1 目标设定原则

本站是**低频高客单、决策周期长**的生意（¥300–800+ 的礼品/定制）。这类生意的 SEO **不能看流量，要看询单**。指标必须分层，否则会为了 PV 做一堆垃圾流量页。

### 2.2 三阶段目标

**短期（0–1 个月）：把地基补到「可被正确理解」**

| 目标 | 可验证标准 |
|---|---|
| 全站商品页有 Product schema | 5 个 `/gifts/{slug}/` 页均含 `Product` + `price` + `priceCurrency` + `availability` |
| 5 个最差页的 title/description 重写 | 每条 title 含 1 个业务核心词且 ≤ 30 字；description 60–80 字且含「送谁/什么/价格带」 |
| 接入 GSC + 百度资源平台看板 | 两个后台均可查到索引量曲线 |
| 百度主动推送恢复正常 | 单日成功推送 > 0 条（当前长期为 0，见 3.4） |

> **达标线**：不是「排名上去了」，而是「百度能正确理解每页是卖什么的、Google 能看到数据」。

**中期（1–3 个月）：建立内容层，抢长尾**

| 目标 | 可验证标准 |
|---|---|
| 上线 12–20 篇「解惑型」内容 | 每篇解决一个具体问题（见 3.3 选题表），≥ 1200 字，含 FAQ schema |
| 场景词落地页补齐 | 「送老师礼物」「乔迁送什么」「开业送什么」三个词各有独立落地页，且与 `/occasions/*`、`/recipients/*` 形成内链网 |
| 站点内链形成拓扑 | 每个商品页至少被 3 个内容页内链指向 |
| 品牌词在百度首页出现 | 搜「小民艺术」首屏可见 xiaominart.com（业主手动验证） |

**长期（3–12 个月）：从「被搜到」到「被信任、被引用、被下单」**

| 目标 | 可验证标准 |
|---|---|
| 长尾词自然排名 | 20+ 个长尾词进入百度前 30（可用站长平台「关键词排名」看） |
| AI 引用可见性 | 在豆包/元宝/DeepSeek 问「送老师什么书法礼物」，答案中引用本站（人工月度抽检 6 个问题） |
| 品牌词被 AI 正确指代 | 问 AI「小民艺术是什么」能准确说出「书法礼品/书画定制」，且不与其他品牌混淆 |
| MTO 准备度 | 商品数据（规格/价格/交期）有稳定 URL 与结构化格式，可供 Agent 抓取 |

### 2.3 策略主轴（一句话版）

> **用「可购买的商品页」承接交易型搜索，用「解惑内容页」承接长尾与 AI 引用，用「实体一致性」承接品牌词 —— 三条线同时走，不追单点排名。**

## 三、逐项执行清单

### 3.1 关键词策略

#### 词的四层分类（本站实际可打的词）

| 层级 | 定义 | 本站示例 | 落地页 | 现阶段优先级 |
|---|---|---|---|---|
| **品牌词** | 搜「我们」 | 小民艺术、xiaominart、小民好礼、小民艺术书法 | 首页 / `/about/` | ⭐⭐⭐ 必守 |
| **核心词** | 品类大词，竞争激烈 | 书法礼品、书画定制、手写字画、企业礼品定制、伴手礼 | `/gifts/` `/custom-commission/` `/business-gifts/` | ⭐⭐ 长期打，短期别指望 |
| **场景词** | 「什么场合送什么」，**意图最明确、转化最高** | 送老师礼物、乔迁送什么、开业送什么、结婚礼物、生日礼物书法、校庆纪念品 | `/occasions/*` `/recipients/*` | ⭐⭐⭐ **主战场** |
| **长尾词** | 具体问题，量小但精准 | 书法作品怎么装裱、手写书法多久能到、字画挂哪个位置、书法礼物多少钱合适 | 待建内容层 | ⭐⭐⭐ **最该补** |

#### 为什么主战场是「场景词 + 长尾词」

- 核心词（如「书法礼品」）首页已被大量电商与资讯站占据，新站硬攻性价比极低；
- 场景词（如「送老师礼物」）用户意图极明确，**且买家会在决策期反复搜**，商品页能直接承接；
- 长尾词是 GEO 的最佳原料 —— AI 回答「送老师什么礼物」时，最可能引用一篇**明确回答了这个问题**的文章。

#### 词表落地要求（⚠️ 需业主确认）

> 本文档**不编造搜索量数据**。词表优先级依据商业意图排序。若要按真实搜索量调整，
> 需业主开通百度指数（免费）或 5118/爱站，导出后我再做一版带量的词表。

#### 现有页面的词位错配（需逐个改）

| 页面 | 现在的 title | 问题 | 建议方向（待业主定稿） |
|---|---|---|---|
| `/` | 小民艺术 XIAOMINART｜方寸藏境，山河入章 | 无业务词 | 保留品牌名 + 补业务词，如「小民艺术｜手写书法礼品与书画定制」 |
| `/works/` | 作品档案｜手写书法原作与装裱一览 | 「作品档案」无人搜 | 改为含「书法原作」「手写」等搜索词 |
| `/scenes/` | 灵感参考｜书法小品适合挂在哪些空间 | 「灵感参考」是内部术语 | 改为「书法挂哪里」类用户语言 |
| `/seasons/` | 四季节气｜小民艺术 | 10 字，信息量为零 | 补「节气礼物」等意图词 |
| `/stories/` | 墙上的故事｜小民艺术 | 10 字，同上 | 补「客户定制案例」类词 |
| `/partners/` | 机构合作｜小民艺术 | 9 字 | 补「博物馆/文旅/出版」对口词 |
| `/artists/` | 艺术家｜Artists｜XIAOMINART | 无业务词 | 补「书法家/主理人」类词 |

> **原则**：title 的写法 = **业务词在前，品牌名在后**，因为搜索结果里品牌名常被折叠。
> 但首页例外 —— 品牌名靠前（守品牌词）。

### 3.2 站内 SEO

#### (a) TDK 标准化

| 项 | 标准 | 现状 |
|---|---|---|
| title 长度 | 中文 **≤ 30 字**（百度约显示 30 个汉字，超出截断） | 多数在 21–27 字 ✅，但**不含业务词** ❌ |
| description 长度 | **60–80 字**，含「是什么 + 送谁 + 价格带 + 行动指引」 | 多在 24–47 字 ❌ |
| title 唯一性 | 全站不重复 | 抽查未见重复 ✅ |
| H1 | 每页恰好 1 个，**含页面主题词** | 数量 ✅，含词 ❌ |
| H2-H3 层级 | 不跳级（H2 下才出 H3） | 首页 11 个 H2，未见跳级 ✅ |

**description 写法模板**（照抄改词即可）：

```
[品类] + [送谁/什么场合] + [核心差异] + [价格带] + [下一步]
例：手写书法礼品，适合送老师、长辈与合作伙伴。每件亲笔书写，
随附释读说明与礼盒，¥300 起。查看选礼指南 →
```

#### (b) 站点结构

当前结构基本合理（首页 → 品类 → 详情，三层），但有两处需改：

1. **`/works/` 与 `/gifts/ready-made/` 职能重叠** —— 一个是「作品档案」，一个是「现货好礼」，内容高度相似。SEO 上是**内部竞争（keyword cannibalization）**。建议二选一作为主入口，另一个 301 或 noindex。（⚠️ 需业主裁决，见第五章）
2. **缺少 `/occasions/` 索引页** —— 有 `/occasions/[slug]/` 动态页，但列表页是否存在需确认；场景词是主战场，必须有聚合入口。

#### (e) Schema Markup（最高优先级的技术项）

**必须补**：

| 页面类型 | 需要补的 Schema | 现状 |
|---|---|---|
| `/gifts/{slug}/`（5 页） | **`Product`** + `offers`（含 `price` / `priceCurrency` / `availability` / `url`） | ❌ **缺失（S1）** |
| `/gifts/ready-made/{slug}/` | Product（已有） | ✅ |
| 内容页（待建） | `Article` + `FAQPage` | 待建 |
| `/business-gifts/` | FAQPage（已有）+ Service | ✅ |

**Product schema 参考结构**（照 `/gifts/ready-made/[slug].astro:37` 复制改字段即可）：

```json
{
  "@type": "Product",
  "name": "琴瑟和鸣 · 婚庆纪念",
  "image": "https://xiaominart.com/assets/scenes/theme-wedding-qin-se-he-ming.jpg",
  "description": "...",
  "brand": { "@type": "Brand", "name": "小民艺术" },
  "offers": {
    "@type": "Offer",
    "url": "https://xiaominart.com/gifts/qin-se-he-ming-gift/",
    "priceCurrency": "CNY",
    "price": "300",
    "priceValidUntil": "2027-12-31",
    "availability": "https://schema.org/InStock",
    "seller": { "@id": "https://xiaominart.com/#organization" }
  }
}
```

> ⚠️ **price 用区间怎么填**：Schema 的 `price` 必须是**单个数字**。
> 建议填**最低价**（300），并在 `description` 里写「¥300–500，按尺寸与装裱浮动」。
> 不要为了好看填 500，那会导致富摘要与实际不符。

### 3.4 站外 SEO 与外链建设

**本站现状：无外链资产**（未做任何外链建设，这是新站常态，不是失误）。

但**这个行业有个天然优势**：书画/礼品/文旅类内容在下面这些平台**有真实的发布场景**，不是硬广：

| 渠道 | 为什么适合本站 | 产出物的形态 | 优先级 |
|---|---|---|---|
| **微信公众号** | 元宝/ima 重点引公众号；且业主可写「一字一源」深度文 | 把 `/works/` 的字源考据改成图文 | ⭐⭐⭐ **最高**（一鱼两吃：GEO + 外链） |
| **小红书** | 礼品决策的主战场，女性用户为主 | 场景图 + 「送老师送什么」话题 | ⭐⭐⭐ |
| **知乎** | 「送老师什么礼物」「企业礼品怎么选」高赞回答常年在首页 | 回答问题 + 末附自家页面 | ⭐⭐ 长尾稳 |
| **豆瓣 / 本地生活** | 文化类内容友好 | 低优先 | ⭐ |
| **行业目录** | 文旅/非遗相关协会、设计平台 | 一次性提交 | ⭐ 低成本 |

**外链质量原则**：
- 宁可 10 条真实相关外链，不要 100 条垃圾目录链（后者会触发降权）；
- **每条外链都指向一个具体内容页**，不要全指首页；
- 业主的真实身份（书法家/主理人）是可被媒体引用的**实体资产**，比任何买链都有效。

> ⚠️ **不做**：买链、链轮、批量目录提交。本站客单价高、品牌敏感，被降权的代价远大于收益。

### 3.5 搜索引擎广告投放（百度 SEM / Google Ads）

**建议：现在不投。** 理由：

| 判断 | 依据 |
|---|---|
| 广告买的是「已经想买的人」，而本站在**落地页说服力**上还有缺口 | 5 个礼品页无 Product schema、description 过短，广告落地转化会被拖低 |
| 高客单低频品类，SEM 单次点击成本高、决策周期长 | ¥300–800 商品，百度「礼品」类词 CPC 常在数元以上，需至少 5–10% 转化才能回本，冷启动期难 |
| **更便宜的第一步是 GEO** | AI 答案是免费的曝光位，本站已有 GEO 基础，继续投入的边际收益远高于 SEM |

**若业主要投，建议的最小验证方案**（不投大词）：

1. **只投长尾 + 品牌防守词**：`小民艺术`（防抢）、`送老师 书法礼物`、`企业 书法礼品 定制`；
2. **日预算 ≤ ¥100，跑 2 周**，只看一个数：**有效咨询数 / 花费**（不看点击率）；
3. **落地页必须是商品详情页**，不能是首页（首页是品牌叙事，不是转化页）；
4. 跑通再放量，跑不通就停 —— 不要「先投着看看」。

**Google Ads**：暂不投。本站 `areaServed` 为中国、语言 zh-CN，海外需求未验证；若要试，只用 **Search 广告 + 英文关键词**（如 `Chinese calligraphy gift`），预算 ¥50/天试 1 个月。

收录数据只能从后台看（前端抓不到）。如果没人看，所有 SEO 动作都是盲打。
