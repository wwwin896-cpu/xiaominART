## 三、当时设计的本意

### 1. 外轮廓：传统量具“斗”的抽象形态

设计注释明确将外轮廓定义为传统量具“斗”的外廓，并强调：

- 稳重；
- 金石感；
- 厚壁；
- 镂空框；
- 古朴厚重。

这里的“斗”不是普通容器图形，而是与“升、斗、小民”这一名称关系相连的传统度量意象。它让品牌名中的“斗”从文字变成了可以识别的印记。

### 2. 整体形式：量具 + 古印

Logo 不是写实地画一个器物，而是将量具外形压缩成印章式边界：

```text
量具外廓
+ 金石古印
+ 镂空透底
= 一个可以用于网页、印章、压印和纸品的品牌印记
```

因此它的核心语义不是“饮品杯”或“普通购物袋”，而是“以传统量具为骨架的文化印记”。

### 3. 中心竖线与弧形笔画：书写 / 文字 / 一笔成形

图形中间的竖向笔画和横向弧形笔势，与项目中另一份品牌方向文档提出的“古文字的一笔”“一笔成形”“字游记”方向相呼应。

但需要区分证据等级：

- **可以确认**：项目品牌方向强调古文字、书写、文字源流、墨色与朱砂；
- **可以合理解释**：中心笔画承担书写、文字和一笔成形的视觉联想；
- **目前不能直接证明**：中心笔画具体对应哪一个汉字、哪一个篆体字或哪句题词。

### 4. 底部圆点：朱砂印记 / 落款 / 点亮的心意

SVG 使用朱砂红，并在中心底部设置圆点。项目品牌方向文档将朱砂解释为：

- 印记；
- 心力；
- 文化温度；
- 中国传统印色的记忆。

因此底部圆点可被理解为一个落款式的朱砂印记：一笔书写完成后，留下一个人的心意和确认。

需要注意：源码注释明确说明了外轮廓的“斗升金石印”概念，但没有单独写出“底部圆点必然代表某一个具体字”。对外使用时应称为“朱砂印记 / 落款式点睛”，不要声称它是某个确定汉字，除非找到原始设计说明。

### 5. 两侧小圆点：辅助印记与构图平衡

完整 Logo 的 SVG 还包含两侧较小的半透明圆点。它们更像辅助性的印记、星点或构图平衡元素，而不是独立图形主体。

项目当前没有对这两个小点给出单独的文字释义，因此不建议对外赋予过度具体的象征意义。

## 五、同项目中存在、但不应混称为同一批“方案二图标”的 Logo

### 1. 纯文字字标：黑色版

```text
public/assets/brand/xiaominart-wordmark-black.svg
```

项目设计评审文档把它定义为另一条“纯文字字标方向”：

- `XIAOMINART` 全大写；
- 高对比衬线字；
- 宽字距；
- 炭黑色；
- 不加图形、不加中文、不加标语。

它是母品牌的 typography-only wordmark，可在需要克制、编辑感或单色印刷时使用，但不是红色“斗升小民印”图标的另一张配色图。

### 2. 纯文字字标：香槟色强调版

```text
public/assets/brand/xiaominart-wordmark-champagne.svg
```

这是黑色纯文字字标的香槟色强调版本，增加一条细金色线。它属于“纯文字字标方向”的变体，不属于红色图标的同批图形变体。

### 3. 两位艺术家子品牌 Logo 方向

项目文档还单独规划过两位艺术家的子品牌 Logo 方向：

#### 升斗小民

设计概念：

- 古文字的一笔；
- 向前行走的路径；
- 墨色线条；
- 朱砂点；
- 字游记；
- 文字源流与知识传播。

#### 非遗小宁

设计概念：

- 面塑人物；
- 打开的故事册；
- 博物馆叙事；
- 陶土赭红；
- 温暖的手工触感。

它们属于“艺术家子品牌方向”，与母品牌的红色量具古印 Logo 是品牌架构中的上下级关系，不是同一批母品牌 Logo 的配色版本。

## 六、关于“斗升小民”与“升斗小民”的名称差异

项目资料存在历史称呼差异：

- Logo SVG 注释使用“斗升小民”；
- 后续品牌内容与当前统一笔名使用“升斗小民”；
- 项目执行方案明确要求不要把旧写法“斗升小民”继续迁移为新内容。

因此应这样理解：

- Logo 的设计概念沿用了“斗 / 升”量具与“小民”的文字双关；
- 当前艺术家对外正式名称应使用“升斗小民”；
- 不建议仅凭 Logo 内部历史注释，把对外品牌名称改回“斗升小民”。

## 七、结论

### 来源结论

这个红色图标是 xiaominART “方案二”品牌标识系统中的独立图标版，项目内的正式源文件是：

```text
public/assets/brand/xiaominart-logo-icon.svg
```

### 设计本意结论

它的核心设计语义是：

```text
传统量具“斗”的外廓
+ 金石古印的镂空边界
+ 中心一笔书写
+ 朱砂落款式圆点
= 小民艺术的文化印记
```

它把“升斗小民 / 斗升小民”这个名称、书写、古文字、朱砂印色和东方手作气质压缩成一个小尺寸可识别符号。

### 同批 Logo 结论

最可靠的“同批次”清单是：

1. `xiaominart-logo-icon.svg`：独立图标 / Favicon；
2. `xiaominart-logo.svg`：标准完整 Logo；
3. `xiaominart-logo-light.svg`：浅色 / 白底版；
4. `xiaominart-logo-dark.svg`：深色版；
5. `xiaominart-logo-full.png` 与 WebP 尺寸文件：完整 Logo 的图片导出。

`xiaominart-wordmark-black.svg` 与 `xiaominart-wordmark-champagne.svg` 是另一条纯文字字标方向；“升斗小民”和“非遗小宁”的图形则是独立的艺术家子品牌方向，不能混称为本红色图标的同批配色版本。
