## CMD-017｜轻量微交互

- 灵感案例卡使用 `[data-reveal]` + `IntersectionObserver`，进入视口时轻微上移淡入。
- CSS 动效仅使用 opacity/transform，避免重型脚本与外部资源。
- 按钮 hover 仅轻微上移与颜色变化；案例 hover/focus 仅轻微提亮。
- `prefers-reduced-motion: reduce` 时取消过渡与位移，内容直接可见。
- 未保留或新增水墨开场动画；首页不被动效阻塞。
- 本次不虚构 FPS、LCP 或 Lighthouse 数据。

## CMD-018｜移动端

- 全局 `input / textarea / select` 最小高度 44px。
- 导航菜单、下拉菜单、Footer 链接、案例筛选与按钮具备可用触控区域。
- 移动端容器宽度使用 `calc(100% - 32px)`，案例卡片和表单允许自然换行。
- 汉堡菜单保留 `aria-expanded`、Escape 关闭与滚动锁定。
- 现有 CSS 未发现为本次改动引入固定宽度横向溢出。
- 未虚构移动端 Lighthouse 评分或 LCP 实测值。

## CMD-019｜无障碍与 SEO

- 站点使用 `header`、`nav`、`main`、`section`、`footer` 等语义元素。
- Logo 与作品概念图具备描述性 alt；作品图使用 `loading="lazy"`、`decoding="async"` 与尺寸属性。
- Lightbox、快速留言、筛选结果和 Newsletter 状态使用 aria 名称/状态播报；交互按钮支持键盘。
- 全局存在 skip link、focus-visible 样式和 reduced-motion 降级。
- 生成 `/sitemap.xml`，robots.txt 指向 `https://www.xiaominart.com/sitemap.xml`。
- Layout 输出 canonical、robots、Open Graph 和 `LocalBusiness` JSON-LD。
- 未执行或声称已完成 Google Search Console 提交；上线后需由站点账号完成。

## CMD-020｜当前页面高亮

- Layout 根据 `Astro.url.pathname` 计算当前路径。
- 当前导航链接添加 `.current` 与 `aria-current="page"`。
- 子路径会高亮对应一级导航；首页使用精确匹配，避免所有页面同时高亮首页。
- 高亮使用品牌朱砂色与底部细线。
