## 先说一个顺序上的更正

我上次说「服务器一到，我当天部署完就切 DNS，你就可以提交备案」——**这个顺序是反的，别按它做。**

原因：阿里云对**未备案域名**在其内地服务器上有拦截。域名一旦提前指过去，打开就是备案提示页，网站直接下线；而备案审核要 2–4 周。

**正确顺序是：先用 IP 把站点跑起来自测 → 提交备案 → 备案通过后再把域名指过来。**

好处是这 2–4 周里，网站继续由 Cloudflare 提供服务，**一天都不断**。

## 第 1 步｜确认地域是中国内地（最关键，先做这个）

**在哪**：阿里云控制台右上搜索框输入「轻量应用服务器」→ 进入 → 服务器列表 → 点实例名

**看什么**：详情页顶部实例名称旁边，或列表里的地域标签

**判断**：

- ✅ 通过：华东1（杭州）、华东2（上海）、华北2（北京）、华南1（深圳）……任何**中国内地**地域
- ❌ 停止：香港、新加坡、日本、美国 —— 境外服务器**无法备案**，配了也白配

**如果是境外**：别往下走了，立刻告诉我。可以去「实例详情 → 退订」退款（5 天内通常全额），重买华东1。

---

## 第 2 步｜设置 root 密码

**在哪**：实例详情页 → 顶部「重置密码」按钮（没有的话看右上角「更多」菜单里）

**怎么设**：

- 12 位以上，含大小写字母 + 数字 + 符号
- 别用生日、品牌名、`xiaomin123` 这类
- 设完会提示需要**重启**才生效 → 点「重启」

**为什么现在设**：部署要用它登录。重启不影响任何东西（网站还没迁过来）。

---

## 第 3 步｜放通 80 和 443 端口

**在哪**：实例详情页 → 左侧「防火墙」标签

**做什么**：看现有规则列表里有没有 `80` 和 `443`。缺哪个补哪个：

1. 点「添加规则」
2. 应用类型下拉选 **HTTP (80)** → 确定
3. 再点「添加规则」→ 选 **HTTPS (443)** → 确定

授权对象保持默认 `0.0.0.0/0`，不要改。协议 TCP。

> ⚠️ 轻量服务器的这个叫「防火墙」，不是 ECS 的「安全组」。别跑去云服务器 ECS 控制台找，找不到的。

**不放通的后果**：部署全对，但打开网站是「连接超时」，而且报错里完全看不出是防火墙——这个坑很费时间。

在实例详情页顶部：

| 要什么       | 长什么样            | 用途            |
| --------- | --------------- | ------------- |
| **公网 IP** | `47.xx.xx.xx`   | 部署、访问、备案填表    |

## 第 5 步｜申请备案服务号

**在哪**：实例详情页 → 左侧「备案服务号」→ 点「申请」→ 选中这个实例

**结果**：得到一串 6 位数字（例如 `123456`）

**注意**：

- 一台服务器通常给 5 个额度，我们只用 1 个
- 拿到后尽快用（长期闲置会失效，失效可重新申请，不花钱）
- **服务器必须和域名在同一个阿里云账号下**。如果当时域名是另一个账号买的，这里会找不到服务器——那就告诉我，有别的办法

## 第 6 步｜取密钥（先看清这条，能省你半小时）

**Cloudflare 里存的 Secret 是「只能写、不能读」的**——存进去之后后台永远看不到明文，没有"显示"按钮。

所以别去 Cloudflare 后台翻，去**源头重新取**：

| 变量                   | 从哪来                                                         | 难度   |
| -------------------- | ----------------------------------------------------------- | ---- |
| `FEISHU_WEBHOOK_URL` | 飞书群 → 右上「…」→ 设置 → 群机器人 → 自定义机器人 → 复制 Webhook 地址             | 1 分钟 |
| `RESEND_API_KEY`     | resend.com 登录 → API Keys → Create → 权限选 Sending access → 复制 | 2 分钟 |
| `FEISHU_KEYWORD`     | 你当初设的那个关键词（忘了就随便设一个新的，我同步改代码）                               | 30 秒 |
| `RESEND_FROM_EMAIL`  | 你已知，形如 `noreply@xiaominart.com`                             | 已知   |
| `RESEND_TO_EMAIL`    | 你已知，收询盘通知的邮箱                                                | 已知   |
| `FORMS_ACCESS_KEY`   | 我们自己定的随机串，**你不用找，我生成一个新的给你**                                | 我来   |

**结论：真正需要你动手的只有前两个 —— 飞书 Webhook 和 Resend API Key。**

> keystatic 在线后台那 4 个密钥（GitHub OAuth 相关）先不用管，不影响网站上线。  
> 后台暂时会不可用，但前台一切正常，等站点稳了我再单独处理。

## 附二｜最容易踩的五个坑（提前知道能省几小时）

1. **端口没放通** → 部署全对，打开超时。第 3 步就是为这个。
2. **服务器在境外** → 备案做不了，所有工作白费。第 1 步先确认。
3. **域名提前指过去** → 备案期间网站打不开，等于关站一个月。所以有开头那段更正。
4. **脚本上传后带 Windows 换行** → Linux 报 `bad interpreter`，报错信息完全看不出原因。我已经用 `.gitattributes` 锁死 LF，你不用管。
5. **服务器到期忘记续费** → 数据直接释放。设日历提醒。
