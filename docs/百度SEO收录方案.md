# 百度 SEO 收录方案：让「小民艺术」/「xiaominart」能搜到官网

> 日期：2026-10-09
> 目标：在百度搜索框输入 **小民艺术** 或 **xiaominart** 时，能搜到 `xiaominart.com`

---

## 一、先分清两个目标，性质完全不同

| 搜索词 | 类型 | 难度 | 原理 |
| ---- | -- | -- | -- |
| `xiaominart` | **品牌词（独有）** | 低 | 全网只有你一家用这个词。百度只要**收录了首页**，搜它基本必出 |
| `小民艺术` | **品牌词（中文）** | 中低 | 中文里可能有同名（如「小民」相关词），需要**站点权重**压过噪音。但配合 `XIAOMINART` 英文站名，识别度足够 |

**关键认知**：这不是"配置某个开关就能生效"的事。百度收录是**爬虫自行决定**的，我们能做的是：
① 让爬虫能爬到、愿意爬（技术侧，已全绿）；② 主动告诉它有哪些页面（推送）；③ 给站点积累权威度（外链/时间）。

## 四、已收录的情况：如何把排名做上去

### 4.1 继续主动推送（配额 10 条/天，项目已自动化）

项目已实现 `scripts/baidu-push.mjs` + CI 自动推送，**每次部署后自动推 URL 给百度**。
受限的是**每天 10 条**的配额，68 条 URL 需要**分 7 天推完**。

```bash
# 手动补推（如需立即全量推，注意每日配额）
cd <repo> && NODE_OPTIONS="" npm run push:baidu
```

> 注意：配额用尽是**正常状态**（脚本会软失败不报错），第二天重跑即可。
> 详见 `docs/数据分析接入指南.md`。

### 4.2 关键词强化 —— 实测已足够，无需改动

**核查数据（2026-10-09）**：首页 HTML 中
- 「小民艺术」出现 **12 次**
- 「XIAOMINART」出现 **14 次**
- 可见正文首段即含 `XIAOMINART / 书画礼品定制`，导航含「关于我们 / 品牌介绍」等品牌语境词

> **结论：品牌词密度充足，标题、正文、JSON-LD 三处均有覆盖。
> 这一项无需做任何改动** —— 网上常见的"关键词堆砌"教学在这里不适用，
> 过度堆砌反而可能被判定作弊。保持现状即可。

（原设想「首页正文品牌词偏少」经实测不成立，已撤销该优化建议。）

### 4.3 外链建设（权重的最主要来源，且**只有你能做**）

百度排名高度依赖「有多少其他网站链接到你」。建议：

| 渠道 | 做法 | 权重 |
| ---- | -- | -- |
| **社交平台** | 小红书/微信/微博/知乎的账号简介或发帖里带 `xiaominart.com` | 中 |
| **行业平台** | 站酷、花瓣等设计/手作社区发布作品并留站 | 中高 |
| **企业信息** | 企查查/天眼查等把官网字段填成 `xiaominart.com` | 高 |
| **软文/报道** | 任何媒体提到你时带上网址 | 高 |
| **友情链接** | 与相关手作/艺术类独立站互换 | 中 |

> **这是最有效也最需要时间的一项** —— 百度对"有外部引用的站点"显著加权重。
> 单靠技术优化，新站品牌词通常需 **2 周–3 个月**自然收录。

## 五、未被收录的情况：最快被收录的三条路

### 路线 A（最推荐）：百度站长平台「普通收录」+ 主动推送

项目**已有 token 和脚本**，只需你确认站长平台里的状态：

1. 登录 [百度搜索资源平台](https://ziyuan.baidu.com/)
2. 确认 `xiaominart.com` 站点已验证（此前用过验证码 `codeva-zpRUfdGBww`，已验证 ✅）
3. 进入 **普通收录 → 推送接口**，看右侧是否显示 **今日剩余配额**
   - 有配额 → 说明接口已激活，跑 `npm run push:baidu` 即可
   - 无配额/未激活 → 需在页面申请开通（即时生效）
4. 同时可在 **普通收录 → sitemap** 提交 `https://xiaominart.com/sitemap.xml`

> ⚠️ **重要**：此前诊断过「今日上限 0 条」，那是**新验证站点配额未释放**的正常状态，
> 需 1–3 天。现在（10-09）应已释放，请在站长平台确认。

### 路线 B：百度「快速收录」（移动端优先，见效最快）

站长平台 → **快速收录** 提交首页 URL。
这是百度给新站的**加速通道**，通常 **1–3 天**内收录。此通道配额独立，与主动推送不冲突。

### 路线 C：确保站长平台只有裸域一个站点（重要）

此前发现：`www.xiaominart.com` 因 **301 跳转**导致验证失败，
你已改用裸域 `codeva-zpRUfdGBww` 验证成功。

**请在站长平台「站点管理」里删掉验证失败的 www 站点** ——
两个域名会被百度当成两个独立站点，**分散权重**。

## 七、常见误区澄清

| 误区 | 真相 |
| ---- | -- |
| 「提交了 sitemap 就该马上搜到」 | sitemap 只是**建议**，不是命令。收录由爬虫排期决定 |
| 「配个 meta 就能上首页」 | meta 是**必要不充分**。排名由内容+外链+时间共同决定 |
| 「花钱能保证收录」 | 百度官方收录**免费**；收费的「快速收录」多为第三方风险渠道，不建议 |
| 「www 和裸域一起提交更好」 | ❌ 相反 —— 会分散权重。**只保留裸域**（已是现状） |
| 「搜不到就是被 K 了」 | 新站**未收录**和**被惩罚**是两回事。先查 `site:` 结果再判断 |
