# xiaominART 首页视觉素材清单

日期：2026-09-29

## 使用说明

本批素材为首页视觉方向与品牌氛围素材，适合用于：

- 首页书法与面塑创作区；
- 品质细节区；
- 手写现货四主题卡片；
- Keystatic 后台的图片字段初始内容；
- 后续真实作品素材到位前的视觉占位。

这些图片是 AI 生成的品牌视觉素材，不应直接标注为某位艺术家的真实作品、真实客户案例、真实博物馆项目或真实现货商品。正式发布真实作品详情、商品参数和成交页面前，应以艺术家提供的实拍素材、真实尺寸、材质、库存和链接替换或复核。


## 五、后台字段建议

每张图片在 Keystatic 中至少维护：

```text
title
caption
image
altText
artist
contentType
relatedPage
relatedTheme
published
usageNote
```

其中 `usageNote` 用于区分：

- 真实作品；
- 品牌氛围图；
- 方向示意图；
- 待授权案例；
- 待补真实产品素材。

## 六、素材上线前检查

- [ ] 真实作品照片到位后，替换对应的方向图；
- [ ] 现货主题接入真实作品名、尺寸、材质、价格和库存；
- [ ] AI 生成画面不写入真实案例、真实客户或博物馆项目描述；
- [ ] 面塑微缩场景不标注为真实历史复原；
- [ ] 所有图片填写准确 alt 文本；
- [ ] 移动端横向滚动裁切不丢失主体；
- [ ] 4:3 图片提供移动端合理裁切；
- [ ] 首页图片懒加载，首屏只优先加载必要资源；
- [ ] 真实视频到位后配置 poster 和 reduced-motion 降级图。
